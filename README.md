# 📦 StockPro – Sistema de Gestão de Estoque

**StockPro** é um sistema moderno de gestão de estoque desenvolvido para empresas de todos os portes. Com uma interface intuitiva, responsiva e de alta performance, a plataforma oferece controle completo do inventário — desde o cadastro de produtos até relatórios detalhados de movimentações.

---

## 📋 Visão Geral

O StockPro foi projetado para simplificar a gestão de estoque sem abrir mão da segurança, desempenho e escalabilidade. A aplicação conta com autenticação robusta, painel administrativo completo, alertas automáticos e relatórios em tempo real — tudo isso com uma experiência de usuário moderna e responsiva.

---

## ✨ Principais Recursos

- 🔐 **Autenticação Segura:** Registro, login, verificação por e-mail e recuperação de senha.
- 📱 **Design Responsivo:** Interface adaptável a desktop, tablets e dispositivos móveis.
- 🚀 **Alta Performance:** Desenvolvido com as mais modernas tecnologias da web.
- 📊 **Dashboard Interativo:** Visualização clara de métricas e dados importantes.
- 🔄 **Atualização em Tempo Real:** Controle instantâneo de movimentações no estoque.
- ⚙️ **Altamente Configurável:** Personalizável conforme as necessidades da empresa.

---

## 🛠️ Tecnologias Utilizadas

- **Next.js 15** – Framework React com renderização híbrida (SSR + SSG)
- **React 18** – Biblioteca para construção de interfaces modernas
- **TypeScript** – Tipagem estática para maior segurança e organização do código
- **Tailwind CSS** – Framework CSS utilitário para estilização rápida e responsiva
- **Shadcn/UI** – Biblioteca de componentes acessíveis e reutilizáveis
- **Appwrite** – Backend-as-a-Service (BaaS) para autenticação e banco de dados
- **Resend** – Serviço confiável de envio de e-mails para verificação e notificações

---

## 🚀 Funcionalidades

### 📦 Gestão de Produtos

- Cadastro completo com nome, descrição, categoria, quantidade, preço e mais
- Organização por categorias e controle de estoque mínimo com alertas
- Histórico completo de movimentações por produto

### 🔐 Autenticação e Segurança

- Registro com verificação de e-mail
- Login seguro com sessões persistentes
- Rotas protegidas para usuários autenticados
- Recuperação de senha via e-mail

### 📊 Dashboard e Relatórios

- Visão geral com métricas do estoque
- Alertas de estoque baixo
- Valor total do inventário em tempo real
- Estatísticas de movimentações (entradas/saídas)

### 🖥️ Painel Administrativo

- Adição, edição e exclusão de produtos
- Busca e filtragem avançadas
- Interface clara, intuitiva e responsiva

### 📋 Pré-requisitos

- Node.js `18.0.0` ou superior
- NPM ou Yarn

### 📥 Instalação

# Clone o repositório
git clone https://github.com/Nycolas2005/stockpro.git

# Acesse o diretório do projeto
cd stockpro

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
